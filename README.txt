EMI Paged Bookmarks
===================

Author: lai

项目简介
--------
为 EMI 的书签栏增加可持久化的分页功能。每个分页可以独立保存书签，并支持自定义名称。

主要功能
--------
- 在 EMI 书签栏顶部增加分页按钮。
- 使用 + 新增分页，使用 - 删除当前分页。
- 删除分页前默认要求确认，按住 Shift 点击 - 可跳过确认。
- 按住 Shift 在 EMI 书签侧栏范围内滚动鼠标滚轮，可循环切换分页。
- 普通鼠标滚轮仍由 EMI 用于切换当前物品列表页。

环境要求
--------
- Minecraft 1.20.1
- Minecraft Forge 47.4.20
- EMI 1.1.24（Forge，必需）
- Java 25

说明
----
未安装 EMI 时，本模组会自动跳过 EMI 相关功能，不影响游戏正常加载。
当前版本暂时只适配上述 EMI 版本。
